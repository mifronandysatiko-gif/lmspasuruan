PANDUAN LENGKAP DEPLOYMENT SERVER PRODUKSI

Aplikasi LMS (Learning Management System) & E-Sertifikat TTE Terintegrasi
Instansi Pengelola BKPSDM Kab. Pasuruan
Sistem Operasi Target Ubuntu 24.04.5 LTS (Noble)
Framework & Bahasa Laravel 12 • PHP 8.3-FPM
Web Server & Database Nginx • MySQL 8.0 • SSL
Konsep Sederhana Arsitektur Server: Agar mudah dipahami, server VPS ini diibaratkan seperti restoran: Nginx bertindak sebagai resepsionis pintu utama, PHP 8.3-FPM sebagai koki yang memproses program, MySQL sebagai gudang bahan data, dan Supervisor sebagai mandor yang menjaga antrean email Google berjalan stabil 24 jam non-stop di latar belakang.
1. Nginx Web Server Menerima lalu lintas HTTP/HTTPS dari internet, menangani berkas statis, dan mengarahkan permintaan ke PHP-FPM.
2. PHP 8.3 & Composer Menjalankan *core framework* Laravel 12, memproses logika kuis, presensi, sertifikat PDF, dan migrasi database.
3. MySQL Database Menyimpan master data pengguna, kurikulum, logbook kepemimpinan, koordinat blanko, dan transaksi sertifikat.
4. Supervisor Queue Worker Memproses antrean pengiriman email token/sertifikat di latar belakang sesuai batasan kuota email Google gratis.
5. Node.js 20 & Vite Melakukan *build* dan kompilasi terhadap pustaka antarmuka pengguna (Tailwind CSS 4 & Alpine.js).
6. Let's Encrypt (Certbot) Menyediakan sertifikat enkripsi SSL HTTPS gratis yang diperpanjang otomatis demi keamanan data pegawai.

1 Akses VPS & Pembaruan Sistem Ubuntu

Buka terminal di komputer Anda (PowerShell di Windows atau Terminal di MacOS/Linux), lalu login ke VPS menggunakan akun root atau user sudo:

# Masuk ke server VPS melalui SSH
ssh root@IP_VPS_ANDA

# Perbarui katalog paket dan perbarui seluruh sistem ke versi keamanan terbaru
sudo apt update && sudo apt upgrade -y

# Atur zona waktu server ke Waktu Indonesia Barat (WIB) agar jam sertifikat & presensi akurat
sudo timedatectl set-timezone Asia/Jakarta

2 Instalasi Web Server Nginx & PHP 8.3 Lengkap

Ubuntu 24.04 LTS secara bawaan sudah menyediakan PHP 8.3 di repositori resminya. Pasang Nginx bersama seluruh ekstensi PHP yang wajib digunakan oleh Laravel 12 dan fitur olah dokumen Excel/PDF:

# 1. Pasang Nginx, Git, Unzip, dan Firewall UFW
sudo apt install -y nginx git curl unzip ufw

# 2. Pasang PHP 8.3-FPM beserta pustaka pendukungnya
sudo apt install -y php8.3-fpm php8.3-cli php8.3-mysql php8.3-common php8.3-mbstring \
php8.3-xml php8.3-bcmath php8.3-curl php8.3-gd php8.3-zip php8.3-intl

Konfigurasi Batas Upload File di PHP (Penting untuk Blanko & Materi)

Buka file konfigurasi PHP-FPM dengan teks editor nano:

sudo nano /etc/php/8.3/fpm/php.ini

Tekan Ctrl + W untuk mencari baris berikut, lalu sesuaikan nilainya menjadi:

upload_max_filesize = 50M
post_max_size = 50M
memory_limit = 256M
max_execution_time = 300

Simpan perubahan dengan menekan Ctrl + O, lalu Enter, dan keluar dengan Ctrl + X. Setelah itu restart PHP-FPM:

sudo systemctl restart php8.3-fpm

3 Instalasi & Pembuatan Database MySQL

Pasang database server MySQL dan buat database khusus aplikasi LMS:

# Pasang MySQL Server
sudo apt install -y mysql-server

# Jalankan panduan pengamanan awal MySQL (opsional)
sudo mysql_secure_installation

# Masuk ke konsol MySQL
sudo mysql

Jalankan perintah SQL berikut di dalam prompt mysql>:

CREATE DATABASE lms_pasuruan CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'user_lms'@'localhost' IDENTIFIED BY 'PasswordKuatLMS2026!';
GRANT ALL PRIVILEGES ON lms_pasuruan.* TO 'user_lms'@'localhost';
FLUSH PRIVILEGES;
EXIT;
Catatan Keamanan: Gantilah kata sandi PasswordKuatLMS2026! dengan kata sandi yang aman dan simpan untuk diisikan ke file .env nanti.

4 Instalasi Composer & Node.js 20 LTS

Aplikasi ini membutuhkan Composer untuk pustaka PHP dan Node.js untuk kompilasi aset frontend:

# 1. Unduh dan pasang Composer secara global
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
sudo chmod +x /usr/local/bin/composer

# 2. Pasang Node.js 20 LTS (NodeSource Repository)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 3. Verifikasi instalasi
composer -V
node -v && npm -v

5 Penempatan Source Code Project ke VPS

Direktori standar aplikasi web di Ubuntu adalah /var/www/lms-pasuruan. Anda dapat memilih salah satu dari dua cara berikut:

Metode A: Melalui Git (Sangat Direkomendasikan)

cd /var/www
sudo git clone https://github.com/username-anda/lms-pasuruan.git lms-pasuruan

Metode B: Upload Manual via FileZilla / WinSCP (SFTP)

  1. Kompres folder project Anda di komputer menjadi file lms-project.zip (Kecualikan folder vendor, node_modules, dan file .env).
  2. Hubungkan FileZilla ke IP VPS dengan port SSH 22.
  3. Upload file zip ke folder /var/www/, lalu ekstrak:
cd /var/www
sudo unzip lms-project.zip -d lms-pasuruan

7 Konfigurasi Virtual Host Nginx

Buat file konfigurasi situs baru di Nginx:

sudo nano /etc/nginx/sites-available/lms-pasuruan

Salin dan tempelkan konfigurasi server block berikut (pastikan root mengarah ke folder /public):

server {
    listen 80;
    listen [::]:80;
    server_name nama-domain-anda.go.id www.nama-domain-anda.go.id; # Ganti dengan domain/IP Anda

    root /var/www/lms-pasuruan/public;
    index index.php index.html;

    client_max_body_size 50M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan situs tersebut dan matikan konfigurasi bawaan Nginx:

# Buat symlink untuk mengaktifkan situs
sudo ln -s /etc/nginx/sites-available/lms-pasuruan /etc/nginx/sites-enabled/

# Hapus konfigurasi default Nginx
sudo rm -f /etc/nginx/sites-enabled/default

# Uji apakah ada kesalahan sintaks
sudo nginx -t

# Muat ulang konfigurasi Nginx
sudo systemctl reload nginx

8 Setup Supervisor (Antrean Email) & Scheduler Cron

Mengapa Supervisor Wajib? Karena sistem email memakai antrean database (antrean Google Mail gratis), jika server ditutup proses antrean akan mati tanpa Supervisor. Supervisor memastikan worker berjalan otomatis dan hidup kembali jika crash. 
# 1. Pasang Supervisor
sudo apt install -y supervisor

# 2. Buat file konfigurasi worker
sudo nano /etc/supervisor/conf.d/lms-worker.conf

Masukkan konfigurasi berikut:

[program:lms-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/lms-pasuruan/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/lms-pasuruan/storage/logs/worker.log
stopwaitsecs=3600

Muat dan aktifkan worker Supervisor:

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start lms-worker:*

# Periksa status worker (harus bertuliskan RUNNING)
sudo supervisorctl status

Pasang Cron Job Otomatis Laravel:

# Buka editor cron milik user www-data
sudo crontab -e -u www-data

Tambahkan baris berikut di baris paling bawah:

* * * * * cd /var/www/lms-pasuruan && php artisan schedule:run >> /dev/null 2>&1

9 Pasang Sertifikat SSL HTTPS Gratis (Certbot)

Setelah nama domain diarahkan (*A Record*) ke IP publik VPS Anda, pasang sertifikat SSL resmi agar website memiliki gembok hijau aman:

# 1. Buka port HTTP dan HTTPS di Firewall
sudo ufw allow 'Nginx Full'
sudo ufw allow OpenSSH
sudo ufw --force enable

# 2. Pasang Certbot untuk Nginx
sudo apt install -y certbot python3-certbot-nginx

# 3. Jalankan sertifikasi SSL otomatis
sudo certbot --nginx -d nama-domain-anda.go.id -d www.nama-domain-anda.go.id
